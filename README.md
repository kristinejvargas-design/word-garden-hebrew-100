# Word Garden — First 100 Hebrew vocabulary trainer

Free, mobile-first biblical Hebrew vocabulary practice: the 100 most frequent Strong’s lemmas, KJV example verses, a flashcard trainer, quick quiz, and local spaced review.

GitHub Pages is published from [`site/`](site/) by the workflow in `.github/workflows/pages.yml`. The editable project copy is maintained in `site/`; this repository is the free public hosting mirror.

Data method, local preview, integration notes, and source credits are in [`site/README.md`](site/README.md) and [`site/sources.html`](site/sources.html).
